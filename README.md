# Namoza Developer Assignment

## Project Overview

This project is a responsive lead generation form built using HTML, CSS, and JavaScript.

## Features

- Responsive layout
- Client-side form validation
- Google Tag Manager dataLayer event
- Clean and simple UI
- Mobile friendly

## Project Files

- index.html
- style.css
- script.js
- schema.md
- integration.md

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Fill out the form.
4. Submit to trigger the dataLayer event.
